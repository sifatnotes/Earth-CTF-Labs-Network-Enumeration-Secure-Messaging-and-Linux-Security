## Categories

- **Secure messaging:** Messaging security and XOR-related challenges.
- **Network reconnaissance:** Nmap scanning, host discovery, and service enumeration.

- **Input security:** LaTeX input handling and command-escape risks.

## Learning Path

1. Begin with Earthly Enumeration to understand discovery concepts.
2. Explore Nmap and service enumeration in an authorized lab.
3. Study hostnames, hosts file behavior, and virtual hosts.
4. Continue with secure messaging and XOR-themed exercises.
5. Finish with filename handling and input-validation security.

Follow each lab's published prerequisites and adjust the order to your experience level.

## How to Use the Labs

1. Choose a challenge from the index.
2. Open its original Learn SecByte page.
3. Review the objectives and setup instructions.
4. Practice only in isolated environments or systems you are authorized to assess.
5. Record findings, relevant tools, and defensive lessons.
